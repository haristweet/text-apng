# 文字APNGメーカー

「配信開始」のカットインや、場所・名前のテロップ、1文字ずつ出る文章を、背景の透けた動く PNG（APNG）にするアプリ。配信・動画・SNS・資料など、どこでも使える文字の素材に。
`index.html` と `apng.js`・`engine.js`・`presets.js`・`app.js` だけで動く（ビルド不要、外部ライブラリなし。字は Google Fonts から読む）。画像と文章はブラウザの外に送らない。

**https://haristweet.github.io/text-apng/**

## できること

- 場面：カットイン（大きな文＋小さな文を真ん中に）・テロップ（場所・日時・名前など。7か所に置ける）・文章（1文字ずつ。空の行でページ送り、長い行は禁則つきで折り返す。真ん中か下の字幕の窓）
- テンプレート24種（配信開始・まもなく開始・休憩中・お知らせ・速報・注意・おめでとう・誕生日・NEW!・セール・結果発表・次回予告・場所・日時・名前・字幕・タイプライターなど）
- 出し方10種（フェード・1文字ずつパッと・大きくして着地・横から滑りこむ・字の間が縮まる・ぼかしから浮かぶ・上から落ちて弾む・奥から近づく・上下から合流・なし）。登場・退場はそれぞれ切れる
- 表示中の動き：点滅・震える・ときどきノイズ（ずれる2色を選べる）
- 字：フォント15種、縁取り・光彩・影・上下の2色・斜め。飾り：帯・上下の線・枠・塗った箱・縦の棒と下線・警告のしま
- 書き出し：APNG（1回再生かずっとくり返す、12〜30こま/秒）と PNG 静止画（完成形）。まわりの透明な余白を切る・APNG が動かない所では完成形を見せる
- 設定はブラウザ（localStorage）に場面ごとに覚える

## しくみのメモ

- **描き方**（`engine.js`）：時刻 t を渡すとその時刻の絵を描く。乱数も時刻と字の番号から作るので、プレビューと書き出しは同じ絵になる。字は1字ずつ「光彩と影」「縁取り」「塗り」の3枚の小さな絵にし、下の層は上の層の形でくり抜いてから3回に分けて重ねる（薄くなっている途中で下の層が透けない）
- **字の大きさ**は画像の面積が同じ 16:9 の高さに対する割合（1280×720 なら高さの割合。800×200 の帯でも小さくなりすぎない）。入りきらなければ縮める
- **表示中の動き**は出きってから 0.1 秒あとに始める（完成形の静止画にノイズや震えを入れない）
- **APNG**（`apng.js`）：前のこまから変わった四角だけを入れ（dispose NONE / blend SOURCE）、同じ絵が続くこまは1枚にまとめて表示時間を延ばす。圧縮は `CompressionStream('deflate')`（無ければ圧縮しない deflate）。行ごとに PNG のフィルタを選ぶ。完成形は fcTL より前の IDAT に入れる（アニメーションのこまには入らない）
- ローカル確認：`python3 -m http.server 8806`

## 試験

- `node test/apng.test.mjs` — APNG の組み立てだけ（Node だけで動く）
- `node test/shots.mjs [出力フォルダ]` — Playwright で、テンプレートごとの「途中・出きった所・消える途中」の一覧（`sheet-*.png`）と 800×200 の帯の一覧を描き、書き出した APNG を読み戻してこまの絵・表示時間を描いた絵と1画素ずつ比べる。画面をクリックと入力でたどる確認も入っている。既定の出力は `test/out/`（リポジトリに入れない）。版を上げるたびに走らせ、前の版の一覧と見比べる
- 前に絵を見て直したこと（「――」の切れ目・文章の塊の位置・完成形に入るノイズ）は、壊れたら落ちる確認として `shots.mjs` に残している
